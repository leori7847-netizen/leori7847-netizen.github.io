# 人工智能图像数据预处理与增强实操

人工智能图像数据预处理与增强实操
工具、设备、场地 普通办公计算机 1 台，开发工具 Python
你作为电网机巡中心的 AI 视觉算法开发人员，现接收到一批无人机拍摄的绝缘
子原始图像数据（存放在本地 raw_images/ 目录下）。为了扩充训练集并提升模型
的抗干扰能力，请你编写一段完整的 Python 脚本，自动化完成以下图像文件的整理
与数据增强任务。
【考核要求与实操任务】
任务一：图片文件的批量命名
编写 Python 代码遍历 raw_images/ 目录下的所有 .jpg 图片文件，将它们按顺
序统一重命名为规范格式：insulator_defect_0001.jpg,
insulator_defect_0002.jpg ... 以此类推。
任务二：图像几何变换
使用 Python 图像处理库（如 OpenCV、PIL 或 Torchvision），遍历上述重命名
后的图片，依次执行以下空间增强操作：
图像随机裁剪： 将原图随机裁剪为 512 x 512 像素的尺寸（若原图小于此尺寸，请先
进行 padding 边缘填充或等比例缩放）。
图像旋转变换： 为了模拟无人机云台受强风影响的轻微抖动，将裁剪后的图像进行
随机角度的旋转，旋转角度范围限制在 [-15°, +15°] 之间，旋转后超出边界的部

分用纯黑色（像素值 0）填充。
任务三：图像光度变换
针对上一步几何变换后的图像，继续执行以下色彩增强操作，以模拟电网巡检
中不同的天气与光照条件：
改变图像亮度： 随机将图像的亮度调高或调低 20%（即亮度调整系数在 0.8 到 1.2
之间随机选取）。
改变图像对比度： 将调整亮度后的图像对比度增强 1.5 倍，使绝缘子的轮廓细节更
加凸显。
任务四：结果输出与保存
将经过所有增强步骤处理后的最终图像，保存至新建的 augmented_images/ 目
录下。保存的文件名需在原命名的基础上增加后缀，例如命名为：
insulator_defect_0001_aug.jpg。
