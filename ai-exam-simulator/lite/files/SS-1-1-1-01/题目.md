# 根据给定的业务数据集，编写一个 Python 脚本实现完整的基础数据清洗与简单分析功能

<div>根据给定的业务数据集，编写一个 Python 脚本实现完整的基础数据清洗与简单分析功能<br>
工具、设备、场地 已安装配置好 python 的电脑一台，并提供业务数据集 business_data.csv<br>
根据给定的业务数据集 business_data.csv（包含<br>
id、order_date、amount、product_name 四列），编写一个 Python 脚本实现完整的<br>
基础数据清洗与简单分析功能。具体要求如下：<br>
1.读取 CSV 格式的业务数据集；<br>
2.将 order_date 列转换为 datetime 日期类型；<br>
3.处理 amount 列的缺失值（用该列平均值填充）；<br>
4.过滤 amount 列中小于 0 的异常值；<br>
5.删除数据集中的重复记录；<br>
6.新增一列 amount_level：根据 amount 值标记区间（≤100 为 “低额”，101-500<br>
为 “中额”，＞500 为 “高额”）；<br>
7.输出清洗后数据的总行数、amount 列的均值和最大值（打印到控制台）；<br>
8.将清洗后的数据集保存为 cleaned_data.csv。</div>
