# 给定中文文本数据集，编写 Python 脚本实现基础的文本特征提取

给定中文文本数据集，编写 Python 脚本实现基础的文本特征提取
工具、设备、场地 已安装配置好 python 的电脑一台，并提供业务数据集 text_classification_data.csv
给定中文文本数据集 text_classification_data.csv（仅包含 content（文本内
容）一列），编写 Python 脚本实现基础的文本特征提取，具体要求如下：
1.读取 CSV 格式的文本数据集；
2.使用 jieba 库对 content 列进行中文分词（分词结果用空格分隔）；
3.去除分词结果中的常见简单停用词（如 “的”“了”“是”“我” 等，自定义简
单停用词列表即可）；
4.将处理后的文本转换为 TF-IDF 特征向量（使用 sklearn 库，无需额外参数配
置）；
5.打印前 3 条文本的分词 + 去停用词结果，以及 TF-IDF 特征向量的形状；
6.将处理后的文本数据保存为 cleaned_text.csv。
7.可以使用 jieba、pandas、sklearn 等库
